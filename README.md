# 行测 / 职测分数计算器 (xcalc)

基于 **Vue 3 + Vite + TypeScript** 与 **腾讯云 EdgeOne Pages (Makers) KV** 的公考《行测》与事业单位联考《职测》估分与复盘 WebUI 工具。支持纯静态离线运行、多端加密云同步、无 AI 量化诊断以及流式 AI 深度复盘。

## 核心功能

- **行测 / 职测双考种隔离切换与 14 套内置预设**
  - **公考《行测》（满分 100 分）**：内置「壹玖 · 均衡对照（130 题）」「2025 / 2024 国考地市级・行政执法（130 题）」「2025 / 2024 国考副省级（135 题）」「河北省考（2025 / 2024，130 题）」「天津市考（2025 / 2024，120 题）」。
  - **事业单位《职测》（满分 150 分）**：内置事业单位联考 A / B / C / D / E 类共 5 套完整模板。
  - 支持一级模块与二级子模块拆分（如「判断推理」细分为图形、定义、类比、逻辑），切换预设时按模块名称自动保留已填题数，支持复制、新建、导出/导入备份。
- **双模式快速计分与试卷命名拼装**
  - 支持「填错题数」与「填正确题数」一键互补切换，`±5 / ±1` 快捷步进、`Enter` 键连续跳转及实时越界保护。
  - 内置试卷名称快捷拼装器（自动根据省份/直辖市追加「省考/市考」）与作答日期、错因备注记录。
- **套卷历史记录与备份**
  - 保存成绩时自动冻结当时的预设快照，后续调整预设不影响历史得分；支持检索、修改名称备注、载入重算以及导出/导入备份文件。
- **混合架构复盘分析（本地量化诊断 + 按需流式 AI 复盘）**
  - **无 AI 量化引擎**：按各模块目标正确率计算「可挽回分值」与提分优先级，按题量动态识别「波动偏大」子模块并独立展示，结合近期滑坡/回暖走势给出针对性教研建议。
  - **流式 AI 复盘**：支持服务端内置模型多路自动容灾（`AI_1_*` ~ `AI_10_*` 环境变量完全解耦配置，首字超时自动切换），也支持填写个人 Gemini（Base URL / Model / API Key）或 OpenAI 兼容接口（仅保存于本地浏览器），支持导出完整提示词与统计摘要 Markdown。
- **多端云同步（EdgeOne KV）**
  - 无需注册账号，本地计算 `SHA-256(空间名称 + 同步口令)` 作为隔离存储键，要求 8 位及以上且含字母数字的强口令；支持**修改同步口令**（云端原子迁移并失效旧口令）以及空数据不落盘、防刷限额保护。

## 本地开发与预览

> 依赖安装在当前项目目录的 `node_modules` 下，不会污染全局环境。

```bash
# 1. 安装依赖
pnpm install

# 2. 复制环境变量模板（可选，用于本地调试云端 AI 或站点配置）
cp .env.example .env.local

# 3. 启动本地开发服务器（自带本地文件模拟 KV：.local-kv.json）
pnpm dev --host 0.0.0.0
```

## 运行测试与构建

```bash
# 单元测试（计分引擎、双模式换算、同步合并、分析引擎、AI 容灾链路）
pnpm test

# 类型检查与生产产物构建（输出至 ./dist）
pnpm build
```

## 部署到腾讯云 EdgeOne Pages / Makers

1. 登录 EdgeOne CLI（或直接在控制台绑定 Git 仓库自动构建）：
   ```bash
   edgeone login -s china
   ```
2. 在 EdgeOne Pages 控制台创建 **KV 命名空间**，并在项目设置中将其**绑定变量名为 `XC_KV`**。
3. **环境变量配置**（参考 [.env.example](./.env.example)）：
   - **站点个性化（可选）**：`VITE_ANALYTICS_SRC`、`VITE_ANALYTICS_WEBSITE_ID`、`VITE_VERCOUNT_SRC`、`VITE_TOP_LINKS`、`VITE_MPS_BEIAN_TEXT`、`VITE_MPS_BEIAN_CODE`、`VITE_ICP_BEIAN_TEXT`。
   - **内置 AI 路由槽位（可选，支持 `AI_1_*` ~ `AI_10_*`）**：
     - `AI_N_BASE_URL`：OpenAI 兼容接口地址
     - `AI_N_API_KEY`：对应密钥
     - `AI_N_MODEL`：模型名称
     - `AI_N_FIRST_TOKEN_MS`：首字超时毫秒数（超时自动降级下一槽位）
     - `AI_N_TIMEOUT_MS`：总超时毫秒数
     - `AI_N_EXTRA_BODY`：可选 JSON 额外参数（如关闭思考模式）
