# 行测分数计算器 (xingce-calculator)

基于 **Vue 3 + Vite + TypeScript** 与 **腾讯云 EdgeOne Pages (Makers) KV** 的行测纸质刷题估分 WebUI 计算器。支持纯静态运行与多用户免注册云端同步。

## 核心功能

- **多套开箱即用预设（支持自定义）**
  - 内置「2025国考地市级/行政执法 130题」「2025国考副省级 135题」「省考联考 120题」等模板，总分均校验至 100 分。
  - 支持一级模块与二级子模块拆分（例如将「判断推理」细分为图形推理、定义判断、类比推理、逻辑判断分别设置分值）。
  - 可复制内置预设或新建自定义预设，支持直接输入「每题分值」或「模块总分」。
- **双模式快速计分**
  - 默认「填错题数」模式，可一键切换「填正确题数」（已录入数值自动互补换算）。
  - 支持输入框 `Enter` 键连续跳转、加减微调按钮及实时越界保护。
- **套卷历史记录**
  - 支持填写「试卷名称」与「备注」保存本次成绩（随记录保存当时的预设快照，后续修改预设不会影响历史分数）。
  - 支持按名称/备注检索、展开查看各模块及子模块得分明细、修改名称备注、载入计算器重新编辑、JSON 导出/导入备份。
- **多用户 EdgeOne KV 云同步**
  - 无需注册账号，浏览器本地计算 `SHA-256(空间名称 + 同步口令)` 作为存储键，不同朋友间数据相互隔离。
  - 采用基于时间戳的增量合并策略（含软删除标记），兼容 EdgeOne KV 60 秒最终一致性。

## 本地开发与预览（不消耗 EdgeOne 云端部署次数）

> 依赖安装在当前项目目录的 `node_modules` 下，不会污染全局环境。

```bash
# 1. 安装依赖
pnpm install

# 2. 启动本地开发服务器（自带本地文件模拟 KV：.local-kv.json）
pnpm dev
```

访问浏览器显示的本地地址即可完整体验前端界面与「云端同步」功能（数据会写入本地 `.local-kv.json`，不会触发云端构建或占用每月部署额度）。

如需暴露给局域网内的手机预览，可运行：

```bash
pnpm dev --host 0.0.0.0
```

## 运行测试与构建

```bash
# 单元测试（计分引擎、双模式换算、同步合并）
pnpm test

# 类型检查与静态产物构建（输出至 ./dist）
pnpm build
```

## 部署到腾讯云 EdgeOne Pages / Makers

1. 确保已在本地登录 EdgeOne CLI（或通过控制台连接 Git 仓库部署）：
   ```bash
   edgeone login -s china
   ```
2. 在腾讯云 EdgeOne Pages 控制台：
   - 创建项目（或使用 `edgeone makers deploy` 上传构建）；
   - 进入 **KV 存储** 创建一个命名空间（Namespace），并在项目设置中将该命名空间**绑定变量名为 `XC_KV`**。
3. 本仓库根目录已配置 `edgeone.json` 与 `edge-functions/api/`（`health.js`、`sync.js`），部署上线后前端会自动识别到 `XC_KV` 并启用多用户云端同步。
